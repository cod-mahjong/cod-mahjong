# 동아리 마작 대회 사이트

랭킹 · 대국 기록 · 선수별 기록 · 순위점 계산기가 있는 정적 사이트입니다.
대회 결과는 **구글 시트**에 입력하면 사이트가 자동으로 읽어와서 랭킹을 갱신합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `config.js` | 대회 이름, 기간(D-day), 구글 시트 주소, 원점/반환점/우마 설정 — **여기만 고치면 됩니다** |
| `index.html`, `style.css`, `app.js` | 사이트 본체 |
| `data/sample.csv` | 시트 주소가 없을 때 보여주는 예시 데이터 (시트 양식 참고용) |
| `apps-script/Code.gs` | 사이트에서 기록 추가/삭제를 하기 위해 **구글 시트에 붙여넣는** 스크립트 |

## 1. 구글 시트 만들기

1. 새 구글 시트를 만들고 첫 줄에 아래 헤더를 넣습니다 (`data/sample.csv`와 같은 양식).

   | 날짜 | 동 | 동 점수 | 남 | 남 점수 | 서 | 서 점수 | 북 | 북 점수 |
   |---|---|---|---|---|---|---|---|---|
   | 2026-11-10 | 김민준 | 42300 | 이서연 | 28100 | 박지호 | 19600 | 최수아 | 10000 |
   |  | 정우진 | 31000 | 강하은 | 30500 | 윤도현 | 24500 | 임채원 | 14000 |

   - 대국 1판 = 1줄. 끝난 순서대로 아래에 계속 추가하면 됩니다.
   - 날짜는 `2026-11-10`, `2026. 11. 10`, `11/10`, `11월 10일` 모두 인식. **비워두면 윗줄 날짜**로 처리됩니다.
   - 같은 날짜 안에서는 시트에 적힌 순서대로 1게임, 2게임… 번호가 자동으로 붙습니다.
   - 자리(동남서북)는 **기가 순서**대로 입력 (동점일 때 순위 판정에 사용).
   - 이름은 매번 **똑같이** 써야 같은 사람으로 집계됩니다 (띄어쓰기 주의).
   - 점수에 쉼표(42,300)가 있어도 괜찮습니다. 칸이 비어 있는 줄은 무시됩니다.
2. **파일 → 공유 → 웹에 게시** → 시트 선택 → 형식을 **쉼표로 구분된 값(.csv)** → 게시.
3. 나오는 주소(`https://docs.google.com/spreadsheets/d/e/.../pub?gid=0&single=true&output=csv`)를 복사해서
   `config.js`의 `gamesCsvUrl: ""` 따옴표 안에 붙여넣습니다.

> 구글 쪽 캐시 때문에 시트를 고친 뒤 사이트에 반영되기까지 **최대 5분** 정도 걸릴 수 있어요.
> 시트 편집 권한은 운영진에게만 주세요. 사이트는 게시된 CSV만 읽습니다.

## 2. 운영자 모드 켜기 (사이트에서 기록 추가·삭제)

시트를 직접 열지 않고 사이트에서 기록을 저장/삭제하려면 아래를 한 번만 해주세요. (약 5분)

1. 구글 시트에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 `apps-script/Code.gs` 내용을 통째로 붙여넣습니다.
3. 맨 위의 `ADMIN_PASSWORD = '여기에-운영자-비밀번호'` 를 운영진만 아는 비밀번호로 바꾸고 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인 (구글 계정 선택 → "고급" → "안전하지 않은 페이지로 이동" → 허용).
     본인이 만든 스크립트라서 뜨는 경고예요.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 `config.js`의 `adminApiUrl: ""` 에 붙여넣습니다.

사용법
- 사이트 맨 아래 **운영자** 버튼 → 비밀번호 입력 → 화면 아래에 "운영자 모드" 표시가 뜹니다.
- **추가**: 점수 계산기에서 선수 4명·점수 입력 → 날짜 확인 → **시트에 기록 저장**.
  처음 오는 선수는 목록 맨 아래 **+ 새 선수** 로 추가합니다.
- **삭제**: 대국 기록 카드 오른쪽 위 **삭제** 버튼.
- 저장/삭제는 시트에 즉시 반영되고, 사이트에도 바로 보입니다(다른 사람 화면에는 최대 5분 뒤).
  방금 저장한 판은 잠시 "반영 대기"로 표시되며 그동안은 삭제할 수 없어요.
- 비밀번호는 Apps Script 안에만 있고 사이트 코드에는 들어가지 않습니다.
  비밀번호를 바꾸려면 `Code.gs`를 고친 뒤 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**.
  (코드를 고칠 때마다 이렇게 새 버전으로 배포해야 반영돼요. URL은 그대로입니다.)

## 3. GitHub Pages로 올리기

1. GitHub에서 새 저장소 생성 (예: `cod_mahjong`, **Public**).
2. 이 폴더의 파일들을 그대로 업로드 (웹에서 *Add file → Upload files* 로 드래그해도 됩니다).
3. 저장소 **Settings → Pages → Branch: `main` / `/(root)` → Save**.
4. 1~2분 뒤 `https://<계정이름>.github.io/cod_mahjong/` 에서 열립니다.

> 주소에서 `/cod_mahjong` 부분까지 없애고 싶으면 저장소 이름을 `<계정이름>.github.io` 로 만들면
> `https://<계정이름>.github.io/` 로 바로 열립니다. 이 경우 계정 이름을 `cod-mahjong` 처럼 지으면 보기 좋아요.
> (GitHub 계정 이름에는 `_`를 쓸 수 없고 `-`만 가능합니다.)

## 점수 계산 방식

- pt = (최종 점수 − 반환점) ÷ 1000 + 우마, 1위는 오카((반환점−원점)×4÷1000) 추가
- 기본값: 원점 25,000 / 반환점 30,000 / 우마 +30 · +10 · −10 · −30 / 오카 +20 (M리그와 동일)
- 예) 34,000점 2위 → +4 + 10 = **+14** / 42,000점 1위 → +12 + 30 + 20 = **+62**
- 배치 5판: 5판 이상 친 선수부터 랭킹·시상 대상, 그 전에는 '배치 중'으로 표시 (`placementGames`)
- 랭킹 점수 = 시작 점수 500 + 누적 pt (`config.js`의 `basePoints`). 순위에는 영향 없음
- 대국 내 동점은 기가 순(동→남→서→북) 상위
- 종합 랭킹 동률은 총 pt → 평균 순위 → 1위 횟수 → 최고 점수 순

## 로컬에서 미리보기

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 접속 (파일을 더블클릭해서 열면 데이터를 못 읽습니다).
